# 点亮 · 我们的共同足迹

把走过的，点亮。一个面向手机、采用新粗野主义风格的中国城市共同足迹地图。

**在线页面：<https://biantai11523.github.io/light-up-china/>**

## 使用

- 点地图或搜索城市，填写称呼、可选的到访日期与记忆，然后点亮。
- 同一个网址、同一份数据。无需账号和口令，任何访问者都能编辑。
- 页面每 15 秒拉取最新足迹，切回页面时也会更新。一次修改只更新一座城市。
- 保存后可撤销；同一城市发生并发修改时会提示冲突，不会静默覆盖。
- 支持拖动、双指缩放、缩放按钮、地区筛选、取消点亮和 JSON 备份导出。
- 使用说明内可以打开示例地图；示例的修改不会上传或影响共同地图。
- 离线时可以查看本机缓存；离线保存不会伪装成成功，内容保留在编辑框中供重试。

## 本地开发

需要 Node.js 24。

```sh
npm ci
npm run dev
```

本地开发默认使用同一云端共享 API，因此本地页面真实点亮也会改变 GitHub 在线地图。开发时如需隔离数据，请使用示例模式或设置 `VITE_API_URL` 指向自己的测试服务。

```sh
npm test
npm run build
npm run preview
```

前端为 Vite + 原生 JavaScript / SVG，地图缩放使用 D3。所有地图与字体资源均随页面部署，不依赖外部地图 CDN。构建产物为普通 HTML、CSS、JavaScript，可以部署到 GitHub Pages。

## 共享架构

GitHub Pages 提供静态页面。共同记录由 Sites 托管的 Cloudflare Worker + D1 保存，服务源代码在 `server/`。

- `GET /api/state`：共同记录和最近 50 次操作。
- `POST /api/session`：自动获得短期匿名会话，用户无需登录。
- `PUT /api/cities/:id`：按城市版本更新，使用操作 UUID 处理重复请求。
- 来源校验、服务端字段校验、匿名会话签名、访问频率限制。
- 数据修改不需要 GitHub 令牌，前端不含任何 GitHub 写入凭证。
- 每次点亮直接改变在线页面读取的共享数据，不会为每一次点亮生成 Git 提交。

匿名会话用于校验请求完整性和控制操作频率，不是身份验证。网站按要求允许所有访问者修改，称呼也由访客自行填写。公开链接并不构成隐私访问限制，请只记录愿意公开的内容。

正式 API：`https://light-up-china-shared-wtx.tingxuan9701.chatgpt.site`

后端发布工作区在本地 `backend/`，独立于 GitHub 源仓库；生成的 D1 迁移在 `server/migrations/` 保留副本。`SESSION_SECRET` 仅存储于服务端运行环境。

## 地图数据

边界来源：[阿里云 DataV.GeoAtlas](https://datav.aliyun.com/portal/school/atlas/area_selector)。可用 `npm run data:fetch` 重新获取并生成 SVG 路径，原始下载缓存位于 `.cache/geo/`。

第一版提供 34 个省级区域、370 个点亮单元，覆盖地级市、自治州、地区、盟、直辖市及省直管县级单位。省界与市界分层绘制，并保留南海诸岛附图。

直辖市、香港、澳门按整体点亮。当前数据源没有提供台湾下一级边界，因此台湾暂按整体点亮。370 是“点亮单元”数，不等同于地级市总数。下载时间保存在 `public/data/china.json`，行政区变动可能晚于数据源版本；本工具用于足迹记录。

地图数据版权归原始数据方所有。本项目代码采用 MIT 许可，Space Grotesk 字体采用 SIL OFL（见 `public/fonts/OFL.txt`）。

## 验证

自动测试覆盖真实 SQLite 上的共享读写、不同城市并发、同城冲突、幂等重试、撤销、字段校验和地图数据完整性，以及 DOM 环境下的搜索 / 点亮 / 第二访客读取 / 示例隔离 / 离线状态。

本次环境关闭了浏览器自动操作，已验证地图 SVG 的栅格化效果；完整移动浏览器的视觉与触摸操作仍需真机验收。
