# 城市点亮地图

面向手机的中国城市地图，采用新粗野主义风格，支持多人共享编辑、高清 PNG 和 SVG 矢量导出。

**在线页面：<https://biantai11523.github.io/light-up-china/>**

## 使用

- 顶部三个按钮分别为“一起去过的地方”“轩宝去过的地方”“曦宝去过的地方”。点击一个分类高亮其足迹，其余记录淡显；再次点击当前分类，恢复完整显示。
- 完整显示只读；选中分类后，新增、编辑、备注和撤销都作用于该分类。共同记录自动计入两个人的视图，个人新增不会反向记为一起去过。
- 三类记录独立保存。现有数据保留为共同记录，通过继承默认显示在两人的个人地图；个人可以保存自己的备注。取消共同记录后，个人视图仍保留各自单独记录的地点。
- 绿色表示一起，薄荷色表示轩宝，浅蓝色表示曦宝；双色纹理表示两人分别去过、但没有共同记录。两人分别去过不会自动算成一起去过。
- 点地图或搜索城市，填写操作人和可选的备注，然后点亮。日期输入已取消；历史日期保留在数据中，不再显示。
- 同一个网址、同一份数据。无需账号和口令，任何访问者都能编辑。
- 页面每 15 秒拉取最新标记，切回页面时也会更新。
- 直接在地图上点击多个城市，再次点击取消选中，然后使用原来的“点亮”按钮统一保存。没有单独的批量入口或操作模式。搜索城市也会加入当前选择。
- 多选保存可统一填写备注；已点亮城市自动跳过，备注留空时保留原有备注。
- 批量修改与历史记录在同一事务中保存；任意城市发生版本冲突时整批不写入。重试不会重复记录，也可整批撤销。
- 保存后可撤销；同一城市发生并发修改时会提示冲突，不会静默覆盖。
- 支持拖动、双指缩放、缩放按钮、地区筛选、取消点亮和 JSON 备份导出。
- 地图下方的“导出图片”提供高清 PNG 和真正的 SVG 矢量文件，保留缩放位置、选中状态、点亮颜色、省市边界和南海附图，附上统计与导出日期。
- PNG 从完整矢量路径按目标分辨率直接绘制，目标长边 4096 像素；近方形图按 1200 万像素上限调整，避免手机内存过高。导出使用较细的省市界线和纯色底，SVG 文件不嵌入位图，支持无损缩放和打印。
- 支持 PNG 预览、下载和受支持设备上的系统分享；手机也可长按 PNG 预览图保存。即使设备无法生成高清 PNG，SVG 下载仍然可用。
- 地图取消容器外框与侧栏限制；手机地图横向铺满，南海附图放在主图下方的独立区域。
- 手机点选城市后显示底部操作条，页面不自动跳转。搜索结果只定位一次地图；拖动、双指缩放结束时不会误选城市。
- 拖动事件按显示帧合并，不在平移过程中重建标签；移动时使用误差控制在亚像素范围的简化边界，松手和导出时恢复完整边界。
- 使用说明内可以打开示例地图；示例的修改不会上传或影响共同地图。
- 离线时可以查看本机缓存；离线保存不会伪装成成功，内容保留在编辑框中供重试。

## 本地开发

需要 Node.js 24。

```sh
npm ci
npm run dev
```

本地开发默认使用同一云端共享 API，因此本地页面真实点亮也会改变 GitHub 在线地图。开发时如需隔离数据，请使用示例模式或设置 `VITE_API_URL` 指向自己的测试服务。

```sh
npm test
npm run build
npm run preview
```

前端为 Vite + 原生 JavaScript / SVG，地图缩放使用 D3。所有地图与字体资源均随页面部署，不依赖外部地图 CDN。构建产物为普通 HTML、CSS、JavaScript，可以部署到 GitHub Pages。

## 共享架构

GitHub Pages 提供静态页面。共同记录由 Sites 托管的 Cloudflare Worker + D1 保存，服务源代码在 `server/`。

- `GET /api/state`：共同记录和最近 50 次操作。
- `POST /api/session`：自动获得短期匿名会话，用户无需登录。
- `PUT /api/cities/:id`：按城市版本更新，使用操作 UUID 处理重复请求。
- `POST /api/cities/batch`：一次提交多个城市，整批版本检查、事务保存、幂等重试。
- `/api/profiles/xuan/cities/:id`、`/api/profiles/xi/cities/:id` 及对应 `/cities/batch` 保存个人记录。原 `/api/cities` 接口仍对应共同记录，兼容旧页面。
- `GET /api/state` 保留旧 `records` / `activity` 字段，同时返回三类独立的 `layers` 和带分类的 `activityAll`。个人记录使用独立内部键，不覆盖原共同记录，无需修改历史数据。
- 来源校验、服务端字段校验、匿名会话签名、访问频率限制。
- 数据修改不需要 GitHub 令牌，前端不含任何 GitHub 写入凭证。
- 每次点亮直接改变在线页面读取的共享数据，不会为每一次点亮生成 Git 提交。

匿名会话用于校验请求完整性和控制操作频率，不是身份验证。网站按要求允许所有访问者修改，称呼也由访客自行填写。公开链接并不构成隐私访问限制，请只记录愿意公开的内容。

正式 API：`https://light-up-china-shared-wtx.tingxuan9701.chatgpt.site`

后端发布工作区在本地 `backend/`，独立于 GitHub 源仓库；生成的 D1 迁移在 `server/migrations/` 保留副本。`SESSION_SECRET` 仅存储于服务端运行环境。

## 地图数据

边界来源：[阿里云 DataV.GeoAtlas](https://datav.aliyun.com/portal/school/atlas/area_selector)。可用 `npm run data:fetch` 重新获取并生成 SVG 路径，原始下载缓存位于 `.cache/geo/`。

第一版提供 34 个省级区域、370 个点亮单元，覆盖地级市、自治州、地区、盟、直辖市及省直管县级单位。省界与市界分层绘制，并保留南海诸岛附图。

直辖市、香港、澳门按整体点亮。当前数据源没有提供台湾下一级边界，因此台湾暂按整体点亮。370 是“点亮单元”数，不等同于地级市总数。下载时间保存在 `public/data/china.json`，行政区变动可能晚于数据源版本；本工具用于足迹记录。

地图数据版权归原始数据方所有。本项目代码采用 MIT 许可，Space Grotesk 字体采用 SIL OFL（见 `public/fonts/OFL.txt`）。

## 验证

自动测试覆盖真实 SQLite 上的共享读写、不同城市并发、同城冲突、幂等重试、撤销、批量全有或全无保存、370 个地区一次提交、字段校验和地图数据完整性，以及 DOM 环境下的地图直接多选 / 再次点击取消 / 原按钮统一保存 / 搜索保留选择 / 丢失响应后重试 / 第二访客读取 / 示例隔离 / 离线状态 / 选城与拖动防误触 / 旧日期保留。拖动测试检查连续事件合帧、文字层不重复更新和完整几何恢复；导出测试检查当前缩放和颜色保留、4K 级 PNG 栅格化、像素预算、纯矢量 SVG 文件、文件下载与 PNG 失败时 SVG 仍可用。

本次环境关闭了浏览器自动操作。已用同一导出 SVG 渲染高清 PNG，并检查全国、放大和分类配色；浏览器原生 Canvas、系统保存面板及触摸操作尚未完成真机验证。现有共享接口仍使用原托管，国内网络可能需要 VPN；没有迁移或新建云服务。
